* Hypothesis testing with maximum likelihood

In your experiments, some of you wrote a decision rule that chooses
the hypothesis with the highest likelihood. Let me formalise this.
You have some parameters $\theta_1$ for hypothesis $H_1$ and some
other parameters $\theta_0$ for $H_0$. To make things unambiguous, the
conditional probability of data $D$, under hypothesis $H_i$, with
parameters $\theta_i$ will be written as $P_i(\cdot \mid \theta_i)$

You then find the maximum likelihood parameters for each case:
\[
\theta^*_i = \arg\max_{\theta_i} P_i(D \mid \theta_i).
\]
This simply means: find the parameter values that make the observed data most likely under hypothesis H_i.
This is exactly the maximum likelihood (ML) estimate you computed in the previous assignment.
Note that the arg⁡max⁡ returns the parameter values achieving the maximum likelihood, not the value of the likelihood itself (that is max).

Afterwards, you choose the hypothesis having the highest likelihood:
\[
H* = \arg\max_{H_i} P_i(D \mid \theta^*_i).
\]
For the same data, you will generally find that *more complex models
have higher likelihood*.

** Example
In the lung cancer example, you can have two simple hypotheses:

$H_0$: Smoking, cancer and asbestos are independent. Then $P_0(S,A,C) = P_0(S) P_0(A) P_0(C)$. These are all binary variables, so you need three parameters: $\theta_{0,S}, \theta_{0,C}, \theta_{0,A}$ for the probability of smoking, cancer and asbestos.

$H_1$: Smoking depends on cancer and asbestos exposure, but smoking and asbestos are independent. Then  $P_1(S, A, C) = P_1(S) P_1(A) P_1(C | A, S)$. So you need $\theta_{1,S}, \theta_{1,A}, \theta_{1,C|AS}, \theta_{1,C|\neg AS}, \theta_{1,C|A \neg S}, \theta_{1,C|\neg A \negS}$, i.e. the probability of cancer given smoking and asbestos has to be defined for all 4 combinations of S and A. So we have 6 parameters.
