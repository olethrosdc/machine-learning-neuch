**** Modelling the conditional expectation $\E[y^t | \xt]$
- Parameters $\param_0, \param_1 \in \Reals$

\[
\pi_\param(\xt) = \param_0 + \param_1 x_{t}
\]

- $y^t = \E[y^t | \xt] + \epsilon_t$, with $\epsilon_t \in \Reals$ being zero-mean *noise*.
- Simplest model: variance $\sigma = \Var(\epsilon) =  \E[\epsilon_t^2]$

*** Two views of the problem
**** Learning as optimisation
#+ATTR_BEAMER: :overlay <+->
- Each value $\pi_\param(x)$ is a *prediction* about the value of $y$
- We suffer a *loss* $\ell(y, \pi_\param(x))$ for every example $(x,y)$ that we see.
- We *can* minimise the average loss over the data 
- Ideally, we *want* to minimise the expected loss, with respect to the unknown distribution $P$.
**** Learning as inference
#+ATTR_BEAMER: :overlay <+->
- The parameters $\param$ define a *probabilistic model* $P_\param(y | x)$ for every value of $y$.
- We want to find the parameters giving the highest *probability* on the observed data.
- Ideally, we want to find the *true conditional distribution $P(y | x)$*.

*** Learning as Optimisation 
Find the parameters $\param$ minimising squared error
\[
\min_\param \frac{1}{T} \sum_{t=1}^T \big[\underbrace{y^t - \pi_\param(\xt)}_{\textrm{residual}}\big]^2
\]

Gauss applied the method of least squares to calculate the orbit of Ceres, an asteroid detected in the solar system. At the time, astronomers were keen to establish what the orbit was, but they did not even know where to point their telescopes. He was the only one who predicted the orbit sufficiently well to tell them where to look. He apparently had already developed the method when he was aged 18, but he only published it much later. He also, of course, famously defined the normal (Gaussian) distribution, which is closely linked to the least-squares method.

*** Maximum likelihood inference
**** Gaussian noise model.
\[
y^t = \pol(\xt) + \epsilon_t,  \qquad \epsilon_t \sim \Normal(0, \sigma)
\]
With conditional density:
\[
p_\param(y^t| \xt)
\propto
\exp(-[y^t - \pol_\param(\xt)]^2 / 2\sigma^2)
\]
\vspace{-1em}
#+BEAMER: \pause
**** Maximum likelihood inference: Find parameters maximising $P_\beta(D)$
\vspace{-1em}
\begin{align*}
\argmax_\param P_\beta(D)
&= 
\argmax_\param \alert<3>{p_\param(y^1, \ldots, y^t| x^1, \ldots, \xt)}
=
\argmax_\param \alert<4>{\ln \prod_t p_\param(y^t| \xt)} \\
&=
\argmax_\param \alert<5>{\sum  \ln} p_\param(y^t| \xt) \\
&= \argmax_\param \sum_t \ln\left\{
\alert<6>{\exp\left(-[y^t - \pi_\param(\xt)]^2 / 2\sigma^2\right)}\right\}\\
&= \argmax_\param \sum_t -[y^t - \pi_\param(\xt)]^2 / \alert<7>{2\sigma^2}
= \argmin_\param \sum_t |y^t - \pi_\param(\xt)|^2
\end{align*}
*** *Gaussian noise model*.
:PROPERTIES:
:BEAMER_ENV: note
:END:
In regression, we can never exactly predict $\yt$. In terms of loss minimisation, we are simply trying to minimise some measure of error in our predictions. However, an alternative approach is to assume that $\yt$ is inherently unpredictable, but that it follows a *specific* distribution, with a mean centered around the prediction $\pol_\vparam(\xt)$. Mathematically, we express this by saying that
 $\yt$ is the result of adding some  noise $\epsilon_t$ to the output of the mean function $\pol(\xt)$,
\[
y^t = \pol_\param(\xt) + \epsilon_t.
\]
Since we have to assume something about the noise, a common assumption is that it is normally distributed. We write this as
\[
\epsilon_t \sim \Normal(0, \sigma),
\]
where $\Normal(0, \sigma)$ means the normal distribution with mean 0 and variance $\sigma^2$. We can also write this in terms of a conditional density function.
\[
p_\param(y^t| \xt)i
\propto
\exp(-[y^t - \pol_\param(\xt)]^2 / 2\sigma^2),
\]
where the proportionality symbol hides the constant $1/\sqrt{2\pi\sigma^2}$.

While the Gaussian noise model is not the only possibility, it has some interesting properties.

*** *Maximum likelihood*.
:PROPERTIES:
:BEAMER_ENV: note
:END:

Now that we have a probabilistic model, we can assign probabilities to the data we have. This is the central idea of the maximum likelihood principle:

- For data $D$, find parameters $\beta$ maximising $P_\beta(D)$.
- Let us apply this principle to our case, and show that maximising the likelihood is the same as minimising the squared errors, when the noise is Gaussian.
  
*Proof details*.
Here, first of all, we only care about predicting $y$ from $x$. For that reason, we define
\[
P_\beta(D) p_\param(y^1, \ldots, y^t| x^1, \ldots, \xt)
\]
We also assume that $\yt$ only depends on $\xt$ if we know the mean and variance,
so that $p_\param(y^1, \ldots, y^t| x^1, \ldots, \xt) = \prod_t p_\param(y^t| \xt)$.

The maximum point of some function $f(\param)$ is the same of some monotonically increasing transformation $g$ of it, i.e. if $f(\param^*) \geq f(\param)$, then
$g[f(\param^*)] \geq g[f(\param)]$. Hence, we can maximise
$\ln \prod_t p_\param(y^t| \xt)$ instead. And since $\ln (a + b) = \ln(a) \ln(b)$.

Finally, note that if $\exp(a) = b$ then $a = \ln(b)$.

** Multiple linear regression
*** Multiple linear regression
**** Input and output
- Data pairs $(\bxt, y^t)$, $t = 1, \ldots, T$.
- Input $\bxt \in \Reals^n$
- Output $\by^t \in \Reals^m$.
#+BEAMER: \pause
**** Point predictions: Modelling the conditional expectation $\E[y^t | \xt]$
- Parameters $\mparam \in \Reals^{n \times m}$
- Function $\pi_\mparam : \Reals^n \to \Reals^m$, defined as
\[
\pi_\mparam(\xt) = \mparam^\top \bxt = \sum_{i=1}^n \vparam_i^\top \xti
\]
**** Probabilistic predictions: Modelling the conditional probability $\Pr[y^t | \xt]$
- $y^t = \E[y^t | \xt] + \epsilon_t$, with $\epsilon_t \in \Reals^m$ being zero-mean *noise*.
- Noise *covariance* matrix $\Sigma = \Var(\epsilon) =  \E[\epsilon_t \mid \epsilon_t \top]$ 

*** Multiple linear regression
:PROPERTIES:
:BEAMER_ENV: note
:END:
Here, both the input and output are multi-dimensional. For that reason, we need an $n \times m$ matrix $\mparam$ to predict the mean.

In fact, since the output has $m$ dimensions, and since the input has $n$, then
\[
\by = \mparam^\top \times \bx
\]
corresponds to a multiplication between matrices of the form
\[
[m,1] = [m,n] \times [n,1].
\]
The other thing that changes is that the noise may be correlated between different output dimensions. For that reason, we are using a *multivariate Gaussian* distribution, with mean $\mparam^\top \times \bx$ and covariance $\Sigma^\top \Sigma$.

* Optimisation algorithms
** Gradient Descent
*** Gradient descent algorithm
**** Minimising a function
\[
\min_\param f(\param) \leq f(\param') \forall \param',
\qquad \param^* = \argmin_\param f(\param) \Rightarrow f(\param^*) = \min_\param f(\param)
\]
#+BEAMER: \pause
**** Gradient descent for minimisation
- Input $\param_0$
- For $n = 0, \ldots, N$:
- $\param_{n+1} = \param_n - \eta_n \nabla_\param f(\param_n)$
#+BEAMER: \pause
**** Step-size $\eta_n$
- $\eta_n$ fixed: for online learning
- $\eta_n = c/[c + n]$ for asymptotic convergence
- $\eta_n = \argmin_\eta f(\param_n + \eta \nabla_\param)$: Line search.

*** Gradient descent for squared error
**** The cost function
$L(\param, D) = \sum_{t=1}^T (y^t - \pi_\param(\xt))^2 =  \sum_{t=1}^T \epsilon_t^2$, with $\epsilon_t \defn y^t - \pi_\param(\xt)$.
#+BEAMER: \pause
**** Cost gradient
Using the chain rule of differentiation, $\nabla_\beta f(\epsilon) = \nabla_\epsilon f(\epsilon) \nabla_\beta \epsilon$.
\begin{align*}
\nabla_\param L(\param, D)
&= \nabla_\param \sum_{t=1}^T \epsilon_t^2
= \sum_{t=1}^T \nabla_\param \epsilon_t^2
= \sum_{t=1}^T \nabla_{\epsilon_t} \epsilon_t^2 \nabla_\beta \epsilon
\\
&
= \sum_{t=1}^T 2 \epsilon_t \nabla_\param[y^t -  \pi_\param(\xt)]
= \sum_{t=1}^T 2 [y^t - \pi_\param(\xt)] [- \nabla_\beta \pi_\param(\xt)]
\end{align*}
#+BEAMER: \pause
**** Parameter gradient for linear regression
Remember $\nabla_\beta f = (\partial / \partial_1 f, \ldots, \partial / \partial_n f)$
\[
\frac{\partial}{\partial \param_j} \pi_\param(\xt) 
=
\frac{\partial}{\partial \param_j} \sum_{i=1}^n \param_i x_{t,i}
=
\sum_{i=1}^n \frac{\partial}{\partial \param_j}  \param_i x_{t,i}
= x_{t,j}.
\]

** Least-Squares
*** Analytical Least-Squares Solution
We need to solve the following equations for $A$:
\begin{equation*}
\begin{matrix}
y^1 &= (\bx^1)^\top \vparam\\
\cdots & \cdots\\
y^t &= (\bxt)^\top \vparam\\
\cdots & \cdots\\
y^T &= (\bxt)^\top \vparam
\end{matrix}
\end{equation*}
#+BEAMER: \pause
We can rewrite it in matrix form:
\begin{equation*}
\begin{pmatrix}
y_1\\
\vdots\\
y_t\\
\vdots\\
y_T
\end{pmatrix}
= 
\begin{pmatrix}
\bx_1^\top\\
\vdots\\
\bx_t^\top\\
\vdots\\
\bx_T^\top
\end{pmatrix}
\vparam
\end{equation*}
#+BEAMER: \pause
Resulting in 
\[
\by = \bX \vparam.
\]
#+BEAMER: \pause
How can we get $\vparam$?

*** Finding the $\param$
We now have a linear equation,
\[
\by = \bX \vparam.
\]
We want to solve for $\param$.
If $\bX$ had an inverse $\bX^{-1}$, we could obtain 
\[
\bX^{-1} \by = \bX^{-1}  \bX \vparam = I \vparam = \vparam.
\]
But $\bX^{-1}$ *does not exist*.

#+BEAMER: \pause
**** Least-squares solution
The *left-pseudo inverse* $\tilde{\bX}^{-1} \defn (\bX^\top \bX)^{-1} \bX^\top$ can be used to obtain
\[
\vparam = \tilde{\bX}^{-1} \by,
\]
This follows as:
\begin{align*}
\by &= \bX \vparam \\
 \tilde{\bX}^{-1} \by &=  \tilde{\bX}^{-1} X \vparam\\
 \tilde{\bX}^{-1} \by &= \underbrace{(\bX^\top \bX)^{-1}}_{\bA^{-1}} \underbrace{\bX^\top \bX}_{\bA} \vparam.
\end{align*}

*** Some matrix algebra reminders
**** The identity matrix $\bI \in \Reals^{n \times n}$
- For this matrix, $I_{i,i} = 1$ and $I_{i,j} = 0$ when $j \neq i$.
- $\bI \bx = \bx$ and $\bI \bA = \bA$.
#+BEAMER: \pause
**** The inverse of a matrix $\bA \in \Reals^{n \times n}$
$\bA^{-1}$ is called the inverse of $\bA$ if
- $\bA \bA^{-1} = \bI$.
- or equivalently $\bA^{-1} \bA = \bI$.
#+BEAMER: \pause
**** The pseudo-inverse of a matrix $\bA \in \Reals^{n \times m}$
- $\tilde{\bA}^{-1}$ is called the *left pseudoinverse* of $\bA$ if $\tilde{\bA}^{-1} \bA = \bI$.
\[
\tilde{\bA}^{-1} = (\bA^\top \bA)^{-1} \bA^\top, \qquad n > m
\]
- $\tilde{\bA}^{-1}$ is called the *right pseudoinverse* of $\bA$ if $\bA \tilde{\bA}^{-1} = \bI$.
\[
\tilde{\bA}^{-1} =  \bA^\top (\bA\bA^\top)^{-1}, \qquad m > n
\]
