* Goal

In this lab you will play the role of a researcher.

Your task is simple:

Find evidence that some variables are predictive of an outcome.

The catch is that there is no true relationship in the data.

The purpose of the exercise is to understand:

- multiple comparisons,
- feature selection,
- model selection,
- train/test contamination,
- researcher degrees of freedom,
- replication.

* Dataset

The provided code generates:

- n individuals,
- p binary genetic markers ("SNPs"),
- a binary outcome.

#+BEGIN_SRC python
import numpy as np

def generate_data(n=500, p=10000, seed=None):
    rng = np.random.default_rng(seed)
    X = rng.integers(0, 2, size=(n, p))
    y = rng.integers(0, 2, size=n)
    return X, y
#+END_SRC

Important:

The outcome y is completely independent of all features.

There is no signal.

* Task 5: Forking paths

Now perform as many analyses as possible.

Examples:

- different numbers of features,
- different train/test splits,
- different feature-selection criteria,
- logistic regression,
- decision trees,
- random forests,
- different random seeds,
- standardisation or not,
- balancing classes or not.

Keep trying until you obtain a result that looks convincing.

Questions:

1. How many analyses did you try?
2. What was your best result?
3. If you only reported the best result, would a reader know how many analyses were attempted?
